# Functions this sysroot's headers declare and the C library does not define.
#
# Checked by scripts/header-check.sh, which fails if a name appears that is not
# listed here. The list may shrink; it may not grow without someone editing this
# file, which is the point — a promise added by accident is caught, and one added
# on purpose is a line in a diff with a reason beside it.
#
# Why the gap is allowed to exist at all. A *declared and undefined* function fails
# at the link, naming itself; that is the good failure, and it is what lets
# libstdc++'s <cmath> compile while nothing in this system computes erf of a
# 128-bit long double. What crates/staros-libc/include/features.h forbids is the
# other thing — a definition that silently does nothing, which moves the failure to
# run time where it names nothing at all.
#
# Roughly: the wide-character family (libstdc++'s <cwchar> requires the
# declarations), the `long double` variants (this target's long double is 128-bit
# quad and nothing here does quad arithmetic), and a tail of stdio, stdlib and
